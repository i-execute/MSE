# MSE · Desktop (Chrome / Edge / Brave — Tampermonkey)

1. Поставьте расширение **Tampermonkey** (Chrome Web Store / Edge Add-ons).
2. Откройте панель Tampermonkey → **Create a new script**, удалите заготовку и вставьте целиком `mse.user.js`.
   Либо перетащите файл в окно браузера — Tampermonkey предложит установку.
3. Сохраните (`Ctrl+S`). В списке скриптов должен появиться **MSE** с зелёной меткой «enabled».
4. Откройте Moodle (`/my` или страницу попытки). Пилюля **MSE** — внизу справа.

## Первый запуск

1. `i` → **шлюз** → адрес `https://…` → **проверить**. Адрес запоминается (localStorage + Storage).
2. `привязать к моему ID` — ID и ФИО берутся со страницы Moodle (или из `/my`, если тема их прячет).
3. Владелец шлюза пускает ID — в панели появляется строка **AI**.

## Заметки

- В Chrome MV3 фоновая страница не нужна: запросы идут из контекста страницы, поэтому «инъекция в iframe»
  в настройках Tampermonkey не требуется.
- Позиция пилюли и журнал сети лежат в localStorage домена Moodle: чистка cookie сайта их сбросит.
- Если в панели видно `ключ не принят` — это статус на стороне шлюза, а не ошибка браузера.
