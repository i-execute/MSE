# MSE · Android (Kiwi / Firefox)

Один и тот же `mse.user.js` работает в любом браузере с поддержкой userscript-ов. Ниже — два проверенных пути.

## Kiwi Browser (Chromium)

1. Поставьте **Kiwi Browser** из Play Store.
2. Меню `⋮` → **Extensions** → включите **Developer mode** → **+ (from file)** → выберите `mse.user.js`.
3. Откройте Moodle (`/my` или страницу попытки) — внизу справа появится пилюля **MSE**.
4. Тап → панель → `i` → **шлюз** → адрес `https://…` → **проверить** → `привязать к моему ID`.

## Firefox for Android

1. Поставьте **Firefox** и [Violentmonkey](https://addons.mozilla.org/android/addon/violentmonkey/) из AMO.
2. Violentmonkey → `+` → **Install from file** (или вставьте содержимое `mse.user.js` в новый скрипт).
3. Убедитесь, что в заголовке скрипта есть `@match` для вашего Moodle (по умолчанию: любые `/my` и страницы
   попыток). Если ваш Moodle не подходит — добавьте строку `// @match https://<ваш-домен>/*` в шапку.
4. Откройте Moodle, панель работает так же, как на iOS.

## Отличия от iOS

- Перетаскивание пилюли — долгим нажатием и переносом (на iOS — обычным перетаскиванием пальцем).
- Жест «назад» в браузере закрывает панель так же, как `×`.

## Если что-то не так

Смотрите таблицу в `Extensions/iOS/README.md` — коды и тексты одинаковые. Дополнительно: в Kiwi после
обновления скрипта иногда нужен перезапуск браузера (кэш расширений), в Firefox — `Violentmonkey → обновить`.
