# MSE 2.3 — один каталог данных, туннель ждёт, расширение переделано в чёрно-белое

Ветка `release/2.3` (от `release/2.2`, HEAD 2.2 — `9c71633`). Владелец прогнал 2.2 на живом стенде и дал список
того, что не работает, плюс «расширение — говно, переделать». Здесь каждый пункт списка закрыт и проверен запуском,
а не на словах.

## Часть A — сервер

### A1/A2 — установка сама поднимает туннель и **ждёт** внешний HTTPS

**Было.** Живой стенд: `tailscale` не залогинен, `url = null`, а снаружи по TLS — `SSL routines::unexpected eof`.
`install.sh` делал `funnel` и сразу перезапускал роутер, поэтому `/health` отдавал пустой адрес, а первый же
внешний запрос падал на сертификате свежего узла.

**Стало.**
- `mse-tunnel.sh wait` переписан: `--timeout` (по умолчанию 60 с), `--quiet` (спиннер в stderr, адрес в stdout),
  `curl -fsSk`, ретрай на `unexpected eof` / `handshake` / `certificate`, понятная причина отказа со подсказкой
  (ACL Funnel, сертификат узла).
- `install.sh` в `setup_tunnel()`: `up` (ключ из первого диалога) → `funnel` → `wait --timeout 60` → **только
  потом** `systemctl restart mse-router.service`. Адрес после `wait` принимается лишь если он `https://…`,
  чтобы молчащий хелпер не мог затереть то, что уже записал funnel.

**Проверка.** `tests/tunnel_test.sh` — 10 проверок запуском: локальный TLS-сервер (`openssl` + `serve.py`),
`wait` возвращает адрес за 0 с при 200 и падает за 6 с с причиной `curl: (7) Failed to connect…` в бюджете,
и порядок строк в `install.sh` — `523 funnel → 535 wait → 558 restart`.

### A3/A4 — один каталог данных, стейт и vault переживают рестарт и обновление

**Было.** `state not saved: ENOENT mkdir /opt/mse/data` — каталог не создавался, стейт не сохранялся; vault
goygram лежал в `/opt/mse/default.vault`, то есть внутри кода, который обновление сносит.

**Стало.**
- `Server/mse-router.js`: единый `DATA_DIR` из `MSE_DATA_DIR`/`MSE_STATE_DIR` (по умолчанию `/var/lib/mse`),
  `ensureDataDir()` (рекурсивно, режим `0700`) до любой записи; там же `state.json`, `admin-token.txt` и vault.
- Настройки владельца — часть состояния: квота, выставленная из панели, теперь переживает рестарт
  (раньше молча возвращалось значение из окружения — найденный по ходу дела настоящий баг потери настроек).
- `install.sh`: `prepare_data_dir()` до старта юнитов (`mkdir 700`, перенос старого `$PREFIX/default.vault`),
  в обоих юнитах `Environment=MSE_DATA_DIR/MSE_STATE_DIR/GOYGRAM_VAULT`, бот работает из каталога данных
  (`WorkingDirectory=$STATE_DIR`, пакет находится через `PYTHONPATH`), в `bot/main.py` сессия mt названа
  внутри каталога данных.

**Проверка.** `tests/state_persistence.py` гоняет **настоящий** роутер: каталога нет до старта → роутер создал его
сам с режимом `700` → allow-лист и квота живы после рестарта → в коде (`opt/`) не появилось ни `data/`, ни vault →
три цикла старт/стоп/старт → «обновление» сносит код и роутер поднимается из свежей копии со старым стейтом.

### A5 — инлайн-режим проверяется при старте

`Bot.check_inline_mode()` (как в OBHOD): `getMe(refresh=True)` → `supports_inline_queries`, запасной признак
`bot_inline_placeholder`, затем сырой `getMe`. Три состояния: `True`, `False`, `None` («не смог определить» — без
ложных тревог). Если `False` — строка в журнал и stderr, **одно** сообщение владельцу в чат, та же строка в
`self_check()` и в блоке «check these first» на панели.

**Проверка.** `tests/inline_mode_check.py` — 16 проверок: off → чат + `self_check` + панель, on → тишина,
сеть упала → `None` и ни одной тревоги.

## Часть B — расширение

### B1 — новый адрес шлюза **заменяет** старый во всех хранилищах

**Было.** Адрес лежал в двух ключах localStorage и в зеркале, при этом панель держала адрес в памяти: после ввода
нового старый оставался в хранилищах и мог «вернуться» после перезагрузки.

**Стало.**
- `MSEBridge.setUrl()` пишет новый адрес в оба хранилища, затем **сканирует** все ключи, похожие на адрес, во всех
  местах (localStorage сайта, хранилище расширения через рантайм, зеркало, старый ключ) и удаляет всё, что не равно
  новому. `audit()` читает с диска и отдаёт список оставшихся «чужих» адресов; `cleared()` — что вычищено.
- Сохраняется только **проверенный** адрес: `checkGateway()` (та же функция, которую зовёт кнопка `check`) сначала
  делает `/health`, и только потом пишет. Список вычищенного уходит строкой в журнал панели.
- Мост читает хранилище расширения через `__mseRuntime.pageStorage()` — единственный бэкенд, который рантайм уже
  выбрал (страничный скрипт объект api не видит).

**Проверка.** `tests/b1_address.test.js` — 2 теста в webkit против **двух настоящих https-шлюзов**, которые считают
попадания: адрес заменён и в localStorage, и в хранилище расширения; старого нет ни в одном месте; после
перезагрузки — тот же результат; `/health` уходит на новый адрес, старый не получает **ни одного** запроса;
непроверенный адрес не сохраняется; очистка чистит всё.

### B2 — воздух в панели

- 8 px между строками, 10–11 px внутри строки, тело панели с полями 12 px.
- Именованные группы с разделителем: `address` / `connection` / `answer` на шлюзе, `account` / `this device` и
  `journal` на аккаунте; фон, линейка и подпись — вместо «стены текста».
- Шапка — имя и **одна** тихая строка под ним (раньше `MSE · question 1` слипалось в строку).
- Ширина панели (300 px) считается от **реального** визуального вьюпорта и всегда оставляет по 8 px с каждой
  стороны; тело ограничено по высоте, панель всегда внутри экрана (нашлось на скриншоте: при 272 px панель
  вылезала за правый край).
- Повторная отрисовка больше не «вспыхивает» целиком: каждая строка поднимается один раз.

**Проверка.** `tests/b2_b3_theme.test.js` (первый тест) измеряет зазоры, паддинги, высоту шапки, число строк в ней,
названия групп и зазор между адресом и кнопками — по живой панели в webkit.

### B3 — строго чёрно-белая тема

**Было.** Сине-голубая палитра (`#a9cdff`, `#0d1420`), свечение вокруг кнопок, три скачанных шрифта.

**Стало.** Один файл темы `Extensions/src/theme.css`, который сборка вставляет в `mse-ui.js` (второй копии нет —
старая палитра удалена из исходника). Палитра: бумага `#0a0a0a`, чернила `#f2f2f2`, линейки `#2a2a2a…#4d4d4d`,
**единственный акцент — белый** (рамка выбранной строки). Свечение осталось только на буквах «MSE» в пилюле;
кнопки вспыхивают белой рамкой и медленно гаснут. Системный шрифт (SF/Segoe/Roboto/Helvetica). Ключ устройства
на экране аккаунта показывается **замаскированным**, а не целиком.

**Проверка.** `tests/b2_b3_theme.test.js` (второй тест) обходит **все** элементы открытой панели и требует, чтобы
ни у одного не было цвета с хью (текст, фон, рамки) — на всех четырёх экранах (ответы, шлюз, журнал, аккаунт);
проверяет белый акцент, отсутствие скачанных шрифтов, свечение только в тексте пилюли и то, что старых значений
палитры нет в собранном файле. Скриншоты: `Storage/screenshots/1-panel-bw.png`, `2-gateway-bw.png`,
`3-account-bw.png`, `4-pill-bw.png`.

  не продукта: каждый тест по отдельности зелёный.
