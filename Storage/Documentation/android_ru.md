# Установка MSE на Android

Данное руководство описывает установку расширения MSE на мобильных устройствах под управлением Android.

---

## 1. Выбор браузера

На платформе Android стандартный мобильный Chrome не поддерживает пользовательские расширения. Рекомендуется использовать один из следующих браузеров:

- **Вариант А (рекомендуемый):** **Firefox для Android** с дополнением **Violentmonkey** или **Tampermonkey**.
- **Вариант Б:** **Kiwi Browser** (Chromium-браузер с поддержкой расширений из Chrome Web Store).

---

## 2. Установка через Firefox для Android

1. Установите **Firefox** из Google Play Store.
2. Откройте Firefox, нажмите меню (три точки) -> **Дополнения** (Add-ons).
3. Найдите и установите дополнение **Violentmonkey** или **Tampermonkey**.
4. В браузере откройте или скачайте файл скрипта:
   - Файл: `Storage/artifacts/mse.user.js`
5. Менеджер скриптов автоматически распознает заголовок userscript и предложит установку. Нажмите **Установить** (Install / Confirm installation).

---

## 3. Установка через Kiwi Browser

1. Установите **Kiwi Browser** из Google Play Store.
2. Перейдите в [Chrome Web Store](https://chrome.google.com/webstore) и установите расширение **Tampermonkey** или **Violentmonkey**.
3. Откройте файл `Storage/artifacts/mse.user.js` в Kiwi Browser.
4. Нажмите кнопку **Установить** в открывшемся окне менеджера скриптов.

---

## 4. Подключение к шлюзу

1. Перейдите в браузере на страницу теста в Moodle.
2. В углу страницы появится пилюля **MSE**. Нажмите на неё.
3. Введите адрес вашего шлюза (Gateway URL, например URL Cloudflared `https://<tunnel-host>.trycloudflare.com` или Tailscale `https://<host>.<tailnet>.ts.net`).
4. Нажмите **Подключиться**. Администратор шлюза получит заявку в Telegram и подтвердит доступ.
5. После подтверждения отобразится статус подключения, лимит дневной квоты и таймер до сброса в 00:00 UTC.
