# Что менялось

## 2.0.0

**Расширение**

- Два уровня доступа. Без регистрации (или пока заявку не приняли) — только строки их базы, к шлюзу **ни одного**
  запроса. После того как владелец пустил Moodle ID — там же строка **AI**: она появляется, когда база пуста,
  ответила ошибкой или тип задания не разбирается; текст растёт по мере ответа, тап ставит его в форму Moodle.
- Фикс полевого отчёта «нет данных страницы: ID»: ID ищется в `M.cfg.userid/userId/user.id`, затем в
  `data-userid`, ссылках на профиль, скрытых полях и в запомненном значении; если страница попытки не знает ID,
  панель один раз сама открывает `/my/` и берёт ID оттуда. Неполный запрос не уходит — панель называет, чего
  именно не хватает.
- Адрес шлюза вводится один раз и проверяется сразу (`/health` → `{"name":"MSE gateway"}`).

**Сервер**

- `mse-router.js`: приём снаружи, ключ устройства + allow-лист по Moodle ID, квота, журнал, прокси на локальный
  AI-бэкенд (`/v1/*`, стрим байт-в-байт). Ключ модели в роутере не живёт.
- tailscale вместо cloudflared: `mse-tunnel.sh` (`install/up/funnel/serve/off/status/url/wait`), стабильный адрес
  `<host>.<tailnet>.ts.net`, адрес сам попадает в `MSE_PUBLIC_URL`.
- `Storage/get.sh` + `Server/stack/install.sh`: установка одной командой, `/opt/mse`, `/etc/mse/mse.env` (600),
  `/var/lib/mse`, systemd-юниты, `sudo mse` (TUI).
- Telegram-панель на goygram: заявки устройств, `/allow`, `/approve`, `/revoke`, `/disallow`, квота, модель,
  журнал, включение/выключение funnel — кнопками и командами.

**Репозиторий**

- `scripts/audit.py --strict`: сканер отпечатков (токены, адреса, чужие пути, живые хосты) — обязательный шаг CI.
- Структура `Server/ · Extensions/{iOS,Android,Desktop} · Storage/ · scripts/ · tests/`.
